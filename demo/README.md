# Dashboard demo data

`portfolio_summary.json` is generated by the deterministic `anaemia-day2
--smoke` workflow. It contains aggregate engineering-demo output only. It does
not contain NFHS participant data, row-level predictions, survey identifiers,
or locked-test results.

The fixture deliberately breaks the synthetic generator's direct predictor to
target signal before model comparison. Its values verify that the complete
pipeline and dashboard execute; they are not research performance estimates.

To regenerate it from the repository root:

```powershell
anaemia-day2 `
  --smoke `
  --output-directory runs/day2-smoke `
  --code-version day2-demo-v1
```

Review `runs/day2-smoke/portfolio_summary.json` and replace the bundled file
only when the schema, disclosure flags, and tests all pass.
